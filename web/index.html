      Add a TfL API key (optional)

      Free at api-portal.tfl.gov.uk — your subscription's primary key. The key stays on this phone; TfL sees it only as the "app_key" on each request. Live times come from Transport for London and are shown as TfL reports them. The station list comes from TfL too, so this page works out by itself which trains really call at the other station.
